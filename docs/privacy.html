DSH Chrome Bridge — Privacy policy

Extension version 0.1.1 · Last updated 2026-11-05

DSH Chrome Bridge is a browser extension that lets a locally running DeepSeek Harness (DSH) agent observe and operate the browser tabs you approve. The extension has no account system, no analytics and no server of its own beyond a loopback WebSocket.

Who processes your data

  • The extension runs inside your browser and talks only to a DSH Host listening on 127.0.0.1 (default port 8765).
  • The DSH Host is software installed on your own machine. It forwards the agent's commands to the extension and returns observations to the model provider configured in your DSH installation.
  • The model provider (for example DeepSeek) receives the page text, accessibility snapshots, screenshots and other observations that the agent asks for — exactly as if a person had pasted that content into a chat. That provider's own terms and privacy policy apply to that content.

The extension itself never contacts a remote server and never collects data for the developer.

What the extension can access

To automate a tab, an agent must first be granted access. The Host keeps a per-domain allowlist; a request from any other domain (or on the blockedDomains list) is refused. Actions are limited to tabs inside the DSH tab group for the current session.

What is stored, and where

  • Locally in chrome.storage.local: the bridge port, an optional auth token you set in the popup, and a random per-install browser id. These stay on your device.
  • Page content (text, accessibility snapshots, screenshots, selected text) is handled in memory and sent to the Host only when an agent tool asks for it. The extension does not write page content to persistent storage.
  • Screenshots that cannot be returned inline may be saved by the Host as files in the DSH workspace on your disk.
  • Nothing is transmitted to the developer, to advertisers, or to a third-party analytics service.

Credentials

The extension does not read passwords, cookies or OAuth tokens, and never types credentials on your behalf. Sites that require a password, one-time code or CAPTCHA are handed back to you through a visible "user takeover" step; you type those values yourself.

Your controls

  • Close the DSH Host, or disable/remove the extension — the agent can no longer connect or act.
  • Revoke access for any domain by removing it from the Host's allowlist, or add it to blockedDomains.
  • Clear the extension's data from chrome://extensions (the popup settings and browser id are removed).
  • Close a DSH tab group: tabs you own are never touched outside it.

Children

The extension is a developer tool and is not directed at children under 13.
